# Capturas de las PR

Rama aparte, sin código: no se fusiona con `main` y no lanza el CI. Cada PR deja sus capturas en una
carpeta con el nombre de su rama (las `/` cambiadas por `-`) y las enlaza en su descripción con
`https://raw.githubusercontent.com/uSources/ilogic-remake/capturas/<carpeta>/<archivo>.png`.
